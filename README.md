# TamKar

منصة متاجر إلكترونية للسوق السوري (الاسم مؤقت).

## شو موجود حالياً

- واجهة متجر بالعربي مبنية من أقسام (بانر، تصنيفات، منتجات، نص وصورة، آراء، واتساب)
- 3 قوالب: `classic` و `bold` و `soft`
- صفحة المنتجات مع بحث وتصنيفات، صفحة منتج، سلة
- طلب بالدفع عند الاستلام، والزبون بيبعت الطلب للتاجر على واتساب
- كل متجر بيفتح على رابطه: `/s/<slug>` أو `<slug>.الدومين` أو دومين التاجر الخاص
- وضع ديمو ببيانات تجريبية إذا ما في Supabase

## التشغيل على الجهاز

```bash
npm install
npm run dev
```

بعدها افتح http://localhost:3000

## الملفات المهمة

| الملف | شو فيه |
|---|---|
| `src/proxy.ts` | تحديد أي متجر حسب الرابط |
| `src/lib/data.ts` | جلب المتاجر والمنتجات وحفظ الطلبات |
| `src/lib/demo-data.ts` | المتاجر التجريبية |
| `src/components/sections.tsx` | أقسام الصفحة الرئيسية |
| `src/app/globals.css` | ألوان وخطوط القوالب |
| `supabase/schema.sql` | قاعدة البيانات وقواعد عزل المتاجر |
